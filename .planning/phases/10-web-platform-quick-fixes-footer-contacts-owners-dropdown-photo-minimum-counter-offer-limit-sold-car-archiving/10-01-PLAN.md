### offers.service.ts — four changes

**Change 1: Expiry check helper.** Add a private method or inline check at the top of both `respondToOffer` and `respondToCounterOffer`:
```typescript
if (
  offer.counterExpiresAt &&
  offer.counterExpiresAt < new Date() &&
  offer.status === 'COUNTERED'
) {
  await this.prisma.offer.update({ where: { id: offerId }, data: { status: 'REJECTED' } });
  throw new BadRequestException('This offer has expired after the 48-hour counter window.');
}
```

**Change 2: Seller counter tracking in respondToOffer.** When `status === OfferResponseStatus.COUNTERED`:
- Check `if (offer.counterAttemptsSeller >= 5) throw new BadRequestException('Counter-offer limit reached. You must Accept or Decline.')` 
- On successful counter update, include:
```typescript
counterAttemptsSeller: { increment: 1 },
lastCounteredBy: 'SELLER',
counterExpiresAt: new Date(Date.now() + 48 * 60 * 60 * 1000),
```

**Change 3: Buyer re-counter path in respondToCounterOffer.** Currently only handles ACCEPTED/REJECTED. Add a new branch for `status === OfferResponseStatus.COUNTERED`:
```typescript
if (status === OfferResponseStatus.COUNTERED) {
  if (!counterAmount || counterAmount <= 0) {
    throw new BadRequestException('Counter amount is required when issuing a counter-offer.');
  }
  if (offer.counterAttemptsBuyer >= 5) {
    throw new BadRequestException('Counter-offer limit reached — awaiting seller final decision.');
  }
  return await this.prisma.$transaction(async (tx) => {
    return tx.offer.update({
      where: { id: offerId },
      data: {
        status: 'COUNTERED',
        buyerCounterAmount: counterAmount,
        counterAmount: counterAmount, // keep in sync
        counterAttemptsBuyer: { increment: 1 },
        lastCounteredBy: 'BUYER',
        counterExpiresAt: new Date(Date.now() + 48 * 60 * 60 * 1000),
      },
    });
  });
}
```
Wrap the expiry check + update in a `$transaction` to prevent race conditions (matches existing pattern in updateStatus/recordSale).

**Change 4: Block new offer after exhaustion.** In `createOffer` (the POST /offers handler), add a check: if a prior offer exists on the same listingId by the same buyerId where `counterAttemptsBuyer >= 5` AND `status` is ACCEPTED or REJECTED (i.e., seller has decided), throw `BadRequestException('You cannot make a new offer on this listing after the negotiation limit has been reached.')`.
