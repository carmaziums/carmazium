    **delivery.service.ts** — REPLACE the skeleton from plan 01 with full implementation:

    Constructor injects: PrismaService, NotificationsService, EmailService, HttpService (from @nestjs/axios), ConfigService.

    `private async getRoadDistanceMiles(originLat, originLng, postcode)`:
    - Calls Google Maps Distance Matrix API using exact URL from RESEARCH.md pattern
    - If element?.status !== 'OK' → throw BadRequestException('Could not calculate road distance to that postcode.')
    - Returns metres / 1609.344 (Float miles)
    - If GOOGLE_MAPS_API_KEY is absent, throw InternalServerErrorException('Delivery distance service not configured.')

    `async createDeliveryRequest(dto: CreateDeliveryRequestDto, buyerId: string)`:
    1. Fetch listing with `include: { seller: { select: { id: true } } }` — throw NotFoundException if not found or not deliveryAvailable
    2. Verify buyer has at least one offer: `prisma.offer.findFirst({ where: { listingId: dto.listingId, buyerId } })` — throw BadRequestException('You must have an offer on this listing to request delivery.') if null
    3. Check for duplicate active request: `prisma.deliveryRequest.findFirst({ where: { listingId: dto.listingId, buyerId, status: { in: ['PENDING', 'ACCEPTED'] } } })` — throw BadRequestException('You already have an active delivery request for this listing.') if found
    4. If listing.latitude is null → throw BadRequestException('The seller has not set a location for this listing.')
    5. Call getRoadDistanceMiles(listing.latitude, listing.longitude, dto.deliveryAddress.postcode)
    6. Radius check: if listing.deliveryMaxMiles && distanceMiles > listing.deliveryMaxMiles → throw BadRequestException('Delivery is not available to your location — outside the seller\'s delivery radius.')
    7. Compute estimatedCostGbp = listing.deliveryPricePerMile ? Math.round(distanceMiles * Number(listing.deliveryPricePerMile)) : 0
    8. Find most recent offerId: `prisma.offer.findFirst({ where: { listingId, buyerId }, orderBy: { createdAt: 'desc' } })`
    9. `prisma.deliveryRequest.create()` with all fields, status PENDING, expiresAt = new Date(Date.now() + 48 * 60 * 60 * 1000)
    10. `notificationsService.create({ userId: listing.sellerId, type: 'DELIVERY_REQUESTED', title: 'Delivery Request Received', message: \`...\`, link: '/dashboard/seller/offers', entityType: 'DELIVERY_REQUEST', entityId: req.id, actionType: 'CREATED', data: { listingId, deliveryRequestId: req.id } })`
    11. Return the created DeliveryRequest

    `async acceptDeliveryRequest(id: string, userId: string)`:
    - Fetch request — throw NotFoundException if not found
    - Lazy expiry check: if status PENDING and expiresAt < now → update to CANCELLED, notify buyer, throw BadRequestException('This delivery request has expired.')
    - ForbiddenException if userId !== request.sellerId
    - BadRequestException if status !== 'PENDING'
    - Update: `{ status: 'ACCEPTED', acceptedAt: new Date() }`
    - Notify buyer (type: 'DELIVERY_ACCEPTED')

    `async declineDeliveryRequest(id: string, userId: string)`:
    - Fetch request — NotFoundException if not found
    - ForbiddenException if userId !== request.sellerId
    - BadRequestException if status !== 'PENDING'
    - Update: `{ status: 'DECLINED', declinedAt: new Date() }`
    - notificationsService.create({ userId: request.buyerId, type: 'DELIVERY_DECLINED', ... })

    `async cancelDeliveryRequest(id: string, userId: string)`:
    - Fetch request — NotFoundException if not found
    - ForbiddenException if userId !== request.buyerId
    - BadRequestException if status !== 'PENDING' with message 'Can only cancel a pending delivery request.'
    - Update: `{ status: 'CANCELLED', cancelledAt: new Date() }`

    `async completeDeliveryRequest(id: string, userId: string)`:
    - Fetch request — NotFoundException if not found
    - ForbiddenException if userId !== request.buyerId
    - BadRequestException if status !== 'ACCEPTED' with message 'Can only mark an accepted delivery request as complete.'
    - Update: `{ status: 'COMPLETED', completedAt: new Date() }`

    `async getMyRequests(buyerId: string)`: findMany where buyerId, include listing select (id, title, deliveryPricePerMile, deliveryMaxMiles)
    `async getReceivedRequests(sellerId: string)`: findMany where sellerId, include listing select (id, title), buyer select (id, firstName, lastName, email)
